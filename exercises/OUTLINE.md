# Sample exercise outline

Progressive practice for internship-oriented Python mentoring.

## 1. Lists

- Reverse a list without `.reverse()` (loop or slicing — explain both)
- Filter even numbers; return a new list
- Flatten a list of lists one level deep

## 2. Dicts

- Count word frequencies in a sentence
- Merge two dicts; later keys win
- Invert a `{id: name}` map to `{name: id}` (handle collisions)

## 3. Functions

- Write `average(nums: list[float]) -> float` with an empty-list guard
- Refactor duplicated logic into a helper
- Add type hints and a one-line docstring

## 4. OOP

- `BankAccount` with `deposit`, `withdraw`, and balance validation
- Compose a `TodoList` class around the CLI data model
- Override `__repr__` for readable debugging

## Stretch

- Add a `--json` flag to the CLI
- Write 2–3 `unittest` or `pytest` cases for one function
